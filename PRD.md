# Build a Premium Full-Stack Developer Portfolio for Atul Prem Narayan

Create a production-quality personal developer portfolio website for **Atul Prem Narayan**, a B.Tech CSE (Hons.) student and aspiring **Full Stack Developer**.

The website should feel like a premium developer-focused product landing page rather than a traditional résumé website.

## PRIMARY DESIGN REFERENCE

Use the visual design language, interaction philosophy, animation quality, spacing, typography hierarchy, and technical/product presentation style of:

https://deepseek.com/harness/en/

Do NOT copy DeepSeek branding, logo, text, illustrations, proprietary assets, or exact content.

Instead, create an ORIGINAL portfolio inspired by the same design principles:

* dark futuristic developer aesthetic
* near-black / deep navy background
* subtle blue atmospheric lighting
* fine technical grid patterns
* floating particles / dots
* large editorial typography
* smooth scroll-based animations
* glass / translucent cards
* soft borders
* minimal blue-white accent palette
* technical UI panels
* terminal/code visual elements
* animated diagrams
* product-style storytelling
* generous whitespace
* restrained visual effects
* extremely polished micro-interactions

The final result should look like a website created by a high-end design/engineering studio.
